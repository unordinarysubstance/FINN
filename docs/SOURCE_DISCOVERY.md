## Important discovery defects and limits

1. **A listing month can disagree with its link.** The TCS Screener row labelled July 2026 also links to an official TCS URL naming Q1 2025-26 and a 10 July 2025 call. That URL was excluded from the latest target set. Always inspect the actual PDF; do not derive a financial period solely from the surrounding month label.
2. **BSE access was denied.** Every BSE document opened for these target records returned HTTP 403. No access-control workaround was attempted. Use a permitted company/exchange source or a manually obtained PDF.
3. **Large PDFs need attention.** The [company-hosted Asian Paints annual report](https://www.asianpaints.com/content/dam/asianpaints/website/secondary-navigation/investors/annual-reports/2025-2026/Integrated-Annual-Report-2025-26.pdf) exceeded the web tool’s 10 MB response limit. The NSE-hosted version was readable through web extraction. This does not establish its downloaded byte size or compatibility with the original 25 MB import limit. The user subsequently confirmed that this annual report exceeds that limit; annual reports now have a shared 100 MB download/import/upload cap.
4. **Web inspection is not runtime verification.** Python in this session cannot resolve external hosts; local socket connections are also denied. URL reachability, redirects, PDF size, page extraction and application ingestion must be checked again from a network-enabled runtime. This task did not bypass those restrictions.
5. **No PDF page-number guesses.** The manifest records identity, not extracted chunks. The actual downloaded PDF must supply citation page boundaries; printed page labels can differ from PDF page indexes.
6. **Publication dates remain incomplete.** A null publication date means unknown. Preserve that distinction instead of substituting retrieval time.

## Import procedure

Use `examples/primary_sources.json` with the preparation CLI when available. Import only `content_verified` entries automatically, and repeat identity/type/period validation on the downloaded bytes. Review `discovered_not_verified` entries manually before assigning periods. If a URL is denied or oversized, record the gap and use a permitted official download/manual upload. Historical fallbacks require explicit selection and must retain their historical titles and periods.
